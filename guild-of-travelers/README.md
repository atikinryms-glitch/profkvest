# 🏰 Гильдия Путников — Профориентационный квест

Интерактивный квест в стиле D&D для профориентации школьников (5-11 классы).

## 🎯 Описание проекта

Веб-приложение, которое помогает школьникам определиться с выбором профессии через игровые ситуации. Проект использует методику Климова (5 типов профессий: Ч-П, Ч-Т, Ч-Х, Ч-Ч, Ч-З) и оформлен в фэнтези-стилистике.

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- pip (Python package manager)

### Установка

1. **Клонируй репозиторий:**
```bash
git clone https://github.com/DnDputnik/guild-of-travelers.git
cd guild-of-travelers
```

2. **Установи зависимости backend:**
```bash
cd backend
pip install -r requirements.txt
```

3. **Настрой переменные окружения (опционально):**
```bash
# Скопируй пример файла .env
cp .env.example .env

# Отредактируй .env своими ключами (если нужны Google Sheets или YandexGPT)
```

4. **Запусти backend сервер:**
```bash
cd backend
uvicorn main:app --reload
```
Сервер запустится на `http://127.0.0.1:8000`

5. **Открой frontend:**
- Открой файл `frontend/index.html` в браузере
- Рекомендуется использовать Live Server в VS Code

## 🎮 Как использовать

1. **Вход:** Введи код класса (например, `8А02`) и имя героя
2. **Оракул:** Пройди тест из 5 случайных вопросов (20 в базе)
3. **Квест:** Пройди 6 случайных ситуаций (20 в базе)
4. **Результат:** Получи рекомендации по профессиям, предметам и вузам
5. **Сохранение:** Сохрани результат в Google Sheets или консоль

## 🔧 Технологии

### Backend
- **FastAPI** — асинхронный веб-фреймворк
- **SQLite** — опционально (можно без БД)
- **Google Sheets API** — сохранение результатов
- **python-dotenv** — переменные окружения

### Frontend
- **HTML5/CSS3** — семантика, анимации, grid/flexbox
- **JavaScript ES6+** — чистый JS без фреймворков
- **Canvas API** — система частиц
- **LocalStorage** — временное хранение данных

## 🌐 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/` | Проверка работоспособности |
| GET | `/api/quest` | Получить все 20 ситуаций |
| POST | `/api/login` | Валидация кода доступа |
| POST | `/api/analyze_answer` | ИИ-анализ свободного ответа |
| POST | `/api/save_result` | Сохранение результата |

## 📊 Google Sheets настройка (опционально)

1. Создай таблицу на [Google Sheets](https://sheets.google.com)
2. Создай сервисный аккаунт в [Google Cloud Console](https://console.cloud.google.com)
3. Скачай JSON-ключ как `backend/google_credentials.json`
4. Дай права редактора email из ключа
5. Вставь ID таблицы в `.env` как `GOOGLE_SHEET_ID`

**Структура таблицы:**
```
Код | Имя героя | Класс | Дата | Тип профессии | Ч-П | Ч-Т | Ч-Х | Ч-Ч | Ч-З | Выборы
```
